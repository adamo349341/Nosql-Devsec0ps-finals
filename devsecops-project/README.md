# DevSecOps Project

This directory contains the final deliverables for the DevSecOps module.

## Structure

- `Pipeline1/` through `Pipeline5/`: pipeline definitions and documentation for each assignment.
- `scripts/`: helper scripts used by pipeline tasks and automation.
- `docker/`: docker files and container assets.
- `kubernetes/`: cluster manifests and deployment YAML.
- `screenshots/`: evidence of pipeline runs, deployments, or tests.
- `docs/`: documentation of the DevSecOps workflow and implementation.
- `rapport_final.pdf`: final DevSecOps report.
- `.gitlab-ci.yml`: GitLab CI pipeline definition.
- `docker-compose.yml`: demo deployment stack.
