# NoSQL Security Project

This directory contains the final deliverables for the NoSQL security module.

## Structure

- `TP1/` through `TP7/`: individual lab work for each practice session.
- `docker/`: Docker assets for local testing or containerizing lab applications.
- `screenshots/`: evidence of testing, exploits, or validation.
- `docs/`: supporting documentation and analysis.
- `rapport_final.pdf`: final report for the NoSQL security module.
- `docker-compose.yml`: example stack for demo applications.
- `requirements.txt`: environment and dependency requirements.
